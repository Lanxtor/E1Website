桌面版

适用于 Windows 和 macOS 的桌面应用

E1 是适用于 Windows 10 或 11（64 位）以及运行 macOS 12 或更高版本的 Apple 芯片 Mac 的桌面应用。两者均已签名，并会自动保持最新。

请从获取 E1下载：会优先提供适合您系统的版本。Windows 应用由 Lanxtor LLC 签名；Mac 应用已由 Apple 签名和公证，因此 macOS 不会显示有关身份不明开发者的警告。首次启动时选择服务器：“使用 E1 Cloud”，或输入您组织自有服务器的地址。使用与浏览器中相同的账户登录，您的项目就在那里。

在桌面应用中，浮动窗口是真正的窗口：将选项卡拖出即可并排工作或放到第二块屏幕上，下次启动时它会在原位置再次打开。应用在启动时以及每隔四小时检查新版本，在后台下载并提示您重启。您无需再次下载安装程序，更新也绝不会回退到旧版本。

浏览器

在浏览器中使用 E1，无需安装

在 E1 中，浏览器是一个完整的工作环境，而不是精简的查看器：打开 app.lanxtor.com 或您组织的 E1 地址并登录，即可用相同的工具打开相同的项目。

浏览器适用于任何计算机，包括没有桌面安装程序的 Linux、Intel Mac 和 Arm 版 Windows。E1 Cloud 已在当前版本的 Google Chrome 和 Microsoft Edge 上测试。在网站的账户页面上，点击“在浏览器中打开 E1”即可直接进入。

E1 会在您操作时将每项更改保存到服务器上。您的选项卡、选择和展开的行保存在服务器上，重新加载后会恢复；外观和面板宽度按浏览器分别保存。在浏览器中，浮动窗口以弹出窗口形式打开。

审查

在笔记本电脑或平板电脑上审阅

在 E1 中，审阅者和查看者在真实模型中工作，而不是在导出的 PDF 中：Reviewer 可以批注、评论和批准，Viewer 以只读方式查看全部内容。

Reviewer 在“批注”图层上用云线、箭头、文字、图钉和图章标注 2D 空间，且永远无法更改图纸。每条批注都有一张卡片，记录其讨论和状态；一轮审阅以意见处理表结束。Viewer 可以在 E1 中直接查看分配给他们的每个项目、图纸、列表和文档。作为访客受邀加入项目的客户和承包商可免费查看。

在平板电脑上，E1 在浏览器中运行。部分界面专为手指操作而设计：接线变更的现场视图以大号行显示每次拆线和接线，轻点一下即可勾选完成一项变更，并记录您的姓名和时间。E1 Reviewer for iPad 和 E1 Mobile for iPhone 即将登陆 App Store，详见获取 E1。

一个项目

同一项目，同一账户，随时随地

在 E1 中，项目存放在服务器上，而不是设备上：桌面应用和浏览器是进入同一数据的两种方式。

在办公桌前用桌面应用开始一项更改，稍后在工厂现场或会议室用浏览器查看。一位工程师的更改会在几秒内由服务器推送给所有打开该项目的人，无需刷新。2D 空间工具栏上的头像显示还有谁打开了它；当两个人更改同一内容时，保留第一次更改，第二次更改会被拒绝并给出明确提示。

一个 E1 许可证仅供一位指定人员使用，每项更改和批准都以该姓名记录。一个账户最多可同时在三处打开，浏览器和桌面应用合并计算。在第四处登录时，E1 会询问要退出哪一处。

  • 桌面应用：Windows 10 或 11（64 位）；Apple 芯片上的 macOS 12 或更高版本。
  • 浏览器：最新版 Google Chrome 和 Microsoft Edge，适用于任何电脑或平板电脑。
  • 服务器：E1 Cloud，或您组织自己的 E1 安装。
  • 更新：服务器和桌面应用在新版本就绪时都会通知您。
问题

工程师常问的问题。

E1 能在 Mac 上运行吗？

可以。桌面应用可在搭载 Apple 芯片、运行 macOS 12 或更高版本的 Mac 上运行，并经过 Apple 签名和公证。在 Intel 芯片的 Mac 上，请在浏览器中使用 E1。

有 Linux 版本吗？

没有 Linux 桌面应用。在 Linux 上，E1 可在浏览器中运行，无需安装任何软件。

浏览器版本与桌面应用相比有功能限制吗？

没有。两者使用同一账户和相同工具，打开同一服务器上的同一项目。桌面应用另外提供真正的浮动窗口（重新打开时保持原位）以及自身的更新功能。

我们可以在 iPad 或其他平板电脑上使用 E1 吗？

可以，在浏览器中使用。E1 Reviewer for iPad 即将登陆 App Store；在此之前，请在平板电脑的浏览器中进行审阅。

桌面应用可以连接到我们自己的服务器吗？

可以。首次启动时，选择“使用 E1 Cloud”或输入您组织的服务器地址（例如 https://e1.example.com），然后点击“连接”。应用会记住该设置。

桌面应用如何更新？

它会在启动时以及每四小时检查一次新版本，在后台下载并提示您重启。应用菜单中的“检查更新…”可立即检查。

我可以同时在笔记本电脑和平板电脑上登录吗？

可以。一个账户最多可同时在三处打开。在第四处登录时，E1 会询问要退出哪一处。
