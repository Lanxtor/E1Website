开始

登录，打开装置，继续工作

在 E1 Cloud 中，您在浏览器中打开 app.lanxtor.com 或启动桌面应用，登录后即可看到您的项目。无需在服务器上安装任何东西。

您可以使用 E1 账户或公司的 Microsoft 账户登录。首次登录即创建您的账户。通行密钥可让您通过屏幕锁或安全密钥登录；Owner 和 Administrator 必须先设置通行密钥，其权限才会生效。一次登录有效期为 12 小时。

您的更改会在操作时即时保存到服务器上，重新加载后，您的选项卡、选择和展开的行都会恢复。状态栏会显示项目的存放位置；在 E1 Cloud 上显示为 Microsoft Azure。E1 Cloud 始终运行最新版本的 E1：服务器更新后，会有提示栏告诉您新版本已就绪，由您选择何时重启进入新版本。

如需试用，请开始30 天免费试用：您将拥有自己的组织，含 5 个 Editor、5 个 Reviewer，以及不限数量、以访客身份邀请的 Viewer。示例项目 Sample E1 提供一个完整的虚构装置供您探索。试用结束后，组织在之后 90 天内为只读状态，所有内容仍可查看和导出。

工作区

项目、数据和团队集中在一个组织中

在 E1 中，一切都属于一个组织：其成员、成员的许可证、组织的项目及其公司库。方案和发票也属于该组织。

Owner 和 Administrator 可通过电子邮件邀请同事并分配许可证，也可从 Excel 一次批量邀请。每人有一个许可证（Editor、Reviewer 或 Viewer），它限定了其角色可执行的操作上限。角色可在组织、项目、分区或单个对象上授予个人或组，组织也可以创建自己的角色。

项目在资源管理器中进行组织，一次查询即可遍历您有权查看的所有项目中的对象。承包商和客户以各自的人员和许可证在共享项目上工作，权限不超过您允许的角色。受邀访问项目的访客可免费查看。

协作

多人同时处理同一装置

在 E1 Cloud 中，多名工程师可同时处理同一项目，并在几秒内看到彼此的更改，由服务器推送，无需重新加载。

二维空间工具栏上的头像显示还有谁打开了它、谁正在编辑。当两人修改同一内容时，保留第一个更改，第二个更改会被拒绝并给出清晰提示，因此不会有内容在不知情时被覆盖。每个对象都保留其历史，记录谁改了什么以及修改前后。

对话始终伴随工作：在对象上发表评论，支持提及和回复；在图纸上固定一条消息；给某人分配任务。收件箱汇集您的提及、回复和任务，您可以选择哪些通知通过电子邮件发送。AI 协同工程师 Alex 在相同的项目中以您的权限工作，绝不超出。

托管

您的数据存放在哪里，以及如何受到保护

E1 Cloud 运行在欧盟境内的一个 Microsoft Azure 区域，即位于爱尔兰的北欧区域。您的项目、图纸、文档及其备份均保存在欧盟境内的 Azure 数据中心。

数据库中的每条记录都属于一个组织，PostgreSQL 行级安全确保 E1 只能读取您当前所在组织的行。数据库没有公网地址。流量仅限 HTTPS，数据库、文件和备份均使用 AES-256 进行静态加密。E1 不保存任何密码。

数据库可恢复到最近 7 天内的任意一分钟，已删除的文件可在 14 天内找回。文件存储在该区域三个独立的数据中心中，已发布的修订绝不会被删除。Owner 和 Administrator 可随时以开放的 JSON lines 格式和原始文件导出整个组织。完整详情请见 E1 Cloud 规格。

  • 区域：EU，Microsoft Azure 北欧（爱尔兰）；美国区域、Amazon Web Services 和 Google Cloud 即将推出。
  • 恢复：最多丢失 1 小时的工作（RPO），8 小时内恢复服务（RTO）。
  • 审计：登录、成员、许可证、角色和导出均有记录，供管理员查看。
  • 支持：LANXTOR 支持人员可查看账户和计费数据，但看不到您的项目、图纸或文档。

问题

工程师常问的问题。

E1 Cloud 是什么？

E1 Cloud 是 LANXTOR 在 app.lanxtor.com 托管的 E1：以软件即服务形式提供的工厂工程软件。LANXTOR 在欧盟境内的 Microsoft Azure 上运行服务器、备份和更新；您只需登录，在浏览器或桌面应用中工作。

我们的数据存储在哪里？

存储在 Microsoft Azure 位于爱尔兰的北欧区域。数据库备份在 Azure 配对的欧盟区域西欧（荷兰）另有一份副本。项目、文件和备份均保留在欧盟境内。

我们需要安装任何东西吗？

不需要。E1 在浏览器中运行，无需安装。适用于 Windows 和 macOS 的桌面应用为可选项，只需点击一次“使用 E1 Cloud”即可连接到 E1 Cloud。

更新如何进行？

E1 Cloud 始终运行最新版本，含更新。服务器更新后，已打开的 E1 会提示新版本已就绪；点击“立即重启”即可打开新版本，您的工作已保存在服务器上。

LANXTOR 员工能打开我们的图纸吗？

不能。LANXTOR 支持人员可查看您的账户和计费数据，以便协助处理许可证和席位，但看不到您的项目、对象、图纸或文档。只有在 Owner 或 Administrator 批准后，才会为支持工单授予访问权限，支持人员的一切操作都会记录在您的审计日志中。

我们如何导出数据？

Owner 或 Administrator 选择“文件 → 组织… → 导出 → 导出全部…”：生成一个归档文件，以开放的 JSON lines 格式包含每张表以及所有文件，最大 4 GB。

试用结束后会怎样？

组织在之后 90 天内变为只读状态。所有内容仍可查看和导出，不会丢失任何数据。
