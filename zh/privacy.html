隐私政策。

我们处理哪些个人数据、为何处理，以及您的权利。本网站不使用任何跟踪，也不使用广告 Cookie。

1. 谁是责任方

根据欧盟和英国《通用数据保护条例》（GDPR），数据控制者为 Lanxtor LLC，地址：7545 Irvine Center Drive, Suite 200, Irvine, California 92618, USA，电子邮件：info@lanxtor.com。公司完整信息请参阅法律声明。

2. 访问本网站

当您打开页面时，托管服务会接收您的浏览器发送的技术数据：IP 地址、日期和时间、所请求的页面、来源页面，以及浏览器和操作系统。这些数据仅用于提供网站并保障其安全，仅在为此所需的期限内保存在服务器日志中，随后删除。

法律依据：我们在网站安全、正常运行方面的合法利益（GDPR 第 6(1)(f) 条）。

3. Cookie 和浏览器存储

本网站只存储其运行所需的内容。它不设置任何跟踪、分析或广告 Cookie，也不从其他公司加载字体或脚本。

  • 语言和货币：您选择的语言和货币，以便下一页显示相同设置（浏览器存储，直到您清除为止）。
  • 登录提示：菜单中显示"账户"还是"登录"（浏览器存储）。
  • 登录会话：您登录 E1 时来自 app.lanxtor.com 的安全 Cookie，用于保持您的登录状态（直到您退出或其过期）。
  • 预览和投票：您在 Academy 预览中的进度以及您在功能看板上的投票，仅保存在您的浏览器中。
  • Cookie 通知：您已看过 Cookie 通知（浏览器存储）。

这些对于提供您所请求的服务是绝对必要的，因此无需征得同意（《电子隐私指令》第 5(3) 条，德国 TDDDG 第 25(2) 条）。您可以随时在浏览器设置中删除它们。如果我们将来添加可选 Cookie，会事先征得您的同意。

4. 您的 E1 账户

当您创建账户并使用 E1 时，我们会处理您的姓名、电子邮件地址、组织、许可、使用情况、Academy 进度和证书，以及您创建的内容。登录由 Microsoft Entra External ID 提供。我们使用这些数据来提供 E1、向您的组织收费并为您提供支持。

法律依据：与您或您的组织签订的合同（GDPR 第 6(1)(b) 条）。数据在账户存续期间保存，之后按税法和商法要求的期限保存。

使用统计，仅在您同意时。E1 会询问每个人一次是否可以与 Lanxtor LLC 共享使用统计，您可以随时在 E1 的"设置 → 使用统计"中更改您的答复。仅在您同意时，E1 才会按天统计您在 E1 中主动工作的时长（仅在您点击或输入时）、点击和按键次数、您使用了哪些功能以及打开了哪些位置。它从不记录您绘制、输入或命名的内容。我们使用这些计数来了解 E1 的哪些部分有帮助、哪些需要改进，并为您的组织提供支持。法律依据：您的同意（GDPR 第 6(1)(a) 条）。停止共享将删除已共享的内容。

试用的来源。如果您点击了我们带有营销活动标签的链接（例如 utm_source=linkedin&utm_campaign=…）然后开始试用，E1 会将该标签与您的组织一起保存：链接来自的平台、营销活动和帖子。这让我们知道哪些帖子和广告带来了试用。该标签仅通过页面地址传递；不会为此在您的浏览器中存储任何内容。法律依据：我们了解哪些营销有效的合法利益（GDPR 第 6(1)(f) 条）。它随组织一同删除。

5. 联系我们

当您通过电子邮件或电话联系我们时，我们使用您的信息来答复您，对于销售咨询，还用于准备报价。法律依据：GDPR 第 6(1)(b) 条和第 6(1)(f) 条。当不再需要这些消息时，我们会将其删除，除非法律要求我们保留。

6. Alex 助手

当您向本网站上的助手 Alex 提问时，您的问题和到目前为止的对话会被发送到我们 Microsoft Azure 账户中的 Azure OpenAI Service，由其撰写回答。请勿输入个人或机密信息。对话仅保存在此浏览器标签页中。法律依据：我们回答有关我们产品问题的合法利益（GDPR 第 6(1)(f) 条）。Microsoft 根据我们的数据处理协议作为处理者为我们处理数据，并且不会将其用于训练 AI 模型。

7. 谁会接收数据

Microsoft Ireland Operations Limited 根据数据处理协议作为处理者，在欧盟境内的 Microsoft Azure 数据中心为我们托管网站和 E1 Cloud。如果数据可能到达欧盟以外的 Microsoft，该传输受《欧盟—美国数据隐私框架》和欧盟标准合同条款的保护。我们不出售个人数据。

对于您的组织放入 E1 Cloud 的数据及其用户的账户，我们根据 E1 数据处理协议（E1 条款与许可协议的一部分）作为处理者为您的组织处理。协助我们处理的公司列于分处理者页面。本声明涵盖我们为自身处理的内容：本网站、联系人、账户的登录安全和计费。

8. 您的权利

您有权访问您的数据、要求更正或删除、限制其处理、数据可携带，以及反对基于合法利益的处理。请写信至 info@lanxtor.com。

您也可以向数据保护机构投诉，例如您居住地的机构：在德国为您所在联邦州的机构，在法国为 CNIL，在西班牙为 AEPD，在挪威为 Datatilsynet，在英国为 ICO。

9. 变更

当我们的网站或服务发生变化时，我们会更新本政策。
