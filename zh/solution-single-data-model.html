一个对象

一个对象，所有视图：唯一可信数据源在 E1 中的含义

在 E1 中，每台泵、阀门、仪表、电缆和功能都是项目数据模型中的一个对象，只在 E1 服务器上存储一次。

E1 中的图纸不保存自己的数据副本。P&ID 上的符号是对象的一次放置，同一个对象可以绘制在多个 2D 空间上。对象的图纸选项卡显示其所在每张图纸的缩略图及完整路径；双击即可打开该图纸，对象已选中并处于视图中。

关于对象的其他一切都在其自己的窗口中，可从浏览器、清单或图纸打开：属性、关系、深度视图、图纸、数据表、聊天、历史和文件。在清单或浏览器中创建的对象可稍后放置到图纸上，方法是从浏览器拖动或使用放置到图纸…，并保留其已有的一切。

由于只有一条记录，就没有需要同步的东西。符号上的属性标签（如带单位的设计压力）始终显示当前值：在清单或数据表中更改它，每个 2D 空间及其 PDF 都会显示新值。不存储任何标签文本。

不同图纸类型之间也是如此。从此 PFD 生成 P&ID…会在新的 P&ID 上绘制 PFD 自身的设备：相同的对象、相同的位号，而非副本，每条物流绘制为相同设备之间的管道。之后添加到 PFD 的内容通过从 PFD 更新绘制。

结构

包含九个部分的工厂数据模型

在 E1 中，每个项目都以相同顺序包含相同的九个部分：Model Space、Unit Operations、Assets、Systems、Processes、Areas、Documents、Tasks 和 Branches。

每个部分保存一类内容。Model Space 保存图纸。Assets 保存设备和仪表，每条绘制的管道、电缆、导线和信号也都是其中的对象。Systems 保存功能分解，Processes 保存步骤、流体和操作工况，Areas 保存厂址、工厂、单元、房间和机柜。右键单击某个部分，会准确列出可在其中创建的内容。

关系将不同部分的对象连接起来：Systems 下的功能“由” Assets 下的泵“实现”，变送器“测量”该泵，机柜“位于”某个房间。您在只显示符合该关系内容的树中选择另一个对象，每个关系都可从两侧查看。

深度视图以卡片和连线显示对象及与其相连的一切，类似对象图而非图纸。从一个阀门出发，您可以沿其端口上的管道追溯到泵、测量它的变送器、它的端子、接在端子上的电缆芯线，以及电缆另一端的接线箱。

对象可包含的内容来自库：对象类、属性、关系类型和图形。Core、Electrical foundation、Plant engineering、CFIHOS 和 NORSOK SCD 等内容包提供现成内容，您的组织可在公司库中添加自己的类和属性，并发布到每个项目。每个量都连同其数值和单位一起存储。

专业

工艺、仪表、电气和自动化数据位于同一批对象上

在 E1 中，每个专业都将其数据添加到同一批对象上，而不是保留自己的工厂副本。

一台离心泵包含工艺数据（操作和设计条件、流体、性能）、机械数据、管道数据、其电机和危险区域的电气数据，以及其信号、报警和跳车的仪表数据。每组数据都是同一数据表的一个部分，由各专业分别填写。

管道表是对项目管线的查询，包含管线号、起点和终点、尺寸、管道等级和设计条件，并与图纸实时同步。回路图在您查看时根据模型绘制，来源是实现某个控制功能的仪表及其接线。“接线”页面显示每个信号从现场电缆到 I/O 通道的完整路径。因果矩阵在 Systems 中的单元上填写，原因和设备从模型中选择。

由于这一切都读取同一批对象，重命名泵、更改其电机额定值或将变送器移到另一个接线箱，都是每个专业都能看到的一次更改。请参阅跨专业协同，了解团队如何同时共享一个项目。

清单

随模型而变的清单、数据表和计算值

在 E1 中，清单是对模型的实时查询，而不是会过时的导出电子表格。

新建查询…会打开项目、部分、文件夹、2D 空间或对象之下所有对象的实时表格。您可以选择列、筛选和分组行，并像在 Excel 中一样编辑单元格；从 Excel 粘贴的数据块在任何更改之前会先预览。一个查询还可以在您有权查看的组织所有项目上运行。

数据仍按工程师习惯的方式导入导出。查询可导出为带 E1 id 列的 Excel、CSV 或 JSON，从 Excel 更新…通过“检查”和“应用”读回文件。位号清单和数据表从 Excel 导入，P&ID 从 DEXPI 2.0、DXF 或 PDF 导入，2D 空间可导出为 DEXPI 2.0，供 3D 设计工具或其他 P&ID 工具使用。

规则确保派生值正确。计算规则根据对象自身的值、其所属对象、相关对象或项目填写属性；该值在同一次更改中随其输入而变化，为什么是这个值？显示规则、每个输入及其来源。没有人手动输入计算值。

历史

每次更改都有记录，每次更改都可撤销

在 E1 中，每次保存的更改都记录在其所涉及的对象上，包含时间、人员以及更改前后的值。

对象的“历史”选项卡以易读的方式列出其更改，撤销此更改可撤回其中一项，即使是较早的更改，只要此后没有人更改过该对象。由 Alex、已保存的助手或导入所做的更改以相同方式记录，并可作为一组撤销。

E1 服务器是模型的唯一写入者，并检查每次更改的权限，无论请求来自何人或何物。正因如此，整个团队以及 AI 协同工程师 Alex 才能在唯一可信数据源上工作，同时清楚地掌握谁更改了什么。

问题

工程师常问的问题。

工厂工程中的唯一可信数据源是什么？

它指工厂的每一项只存储一次，每张图纸、清单和文档都显示这一条记录。在 E1 中，一台泵就是一个对象；P&ID、数据表、管线表和接线都读取它，因此没有需要核对的副本。

一个对象可以绘制在多张图纸上吗？

可以。对象可以放置在多个 2D 空间上，其“图纸”选项卡列出它所在的每张图纸。PFD 和由其生成的 P&ID 绘制的是相同的设备对象，位号也相同。

我还能得到 Excel 清单吗？

可以。任何查询都可导出为 Excel、CSV 或 JSON，“从 Excel 更新…”读回更改，并在应用任何内容之前进行检查。E1 中的清单本身始终与模型实时同步。

数据模型使用哪些内容包和标准？

E1 提供 Core、Electrical foundation、Plant engineering、CFIHOS、NORSOK SCD、Specification、Wire harness 和 Marine 等内容包。您的组织可以在公司库中添加自己的类和属性。

我可以从其他工具导入 P&ID 吗？

可以。E1 可导入 DEXPI 2.0 文件、来自 CAD 的 DXF 格式 P&ID、导出为 PDF 的 P&ID，以及来自 Excel 的位号清单和数据表。再次运行 DEXPI 导入会更新已有内容，而不是重复创建。

一个模型可以有多大？

我们的负载测试在一个炼油厂规模的项目上运行，包含 498,000 个对象和 1,300 张高密度图纸。实测时间请参阅为炼油厂规模项目而构建和 E1 Cloud 规格。
