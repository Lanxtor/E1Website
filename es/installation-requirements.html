Base de datos

La base de datos decide lo rápido que es E1.

Qué elegir

  • Base de datosPostgreSQL 16
  • En Microsoft AzureAzure Database for PostgreSQL – Flexible Server, General Purpose (D2ds_v6 para una prueba, D4ds_v6 para hasta 50 ingenieros)
  • En tus propios servidoresNúcleos dedicados y SSD local o una SAN con las IOPS de arriba
  • ConexionesAl menos 300 para E1: cada servidor E1 abre 41
  • Réplica en esperaUna copia en otra zona de disponibilidad que toma el relevo por sí sola, para el trabajo diario
  • Copias de seguridadRecuperación a un momento dado, conservadas 35 días

Qué no elegir

  • Bases de datos burstable o de núcleos compartidos (Azure Burstable serie B y similares): cuando agotan sus créditos de CPU bajan a una fracción de un núcleo, y E1 tarda segundos en cada clic.
  • Discos pequeños y lentos: un disco de 32 GB da 120 IOPS, muy pocas para ingenieros que trabajan a la vez.
  • Una base de datos lejos del servidor E1: otra región u otro centro de datos añade su retraso a cada paso de cada clic.
  • Una base de datos compartida con otras aplicaciones: su carga se convierte en el tiempo de espera de tus ingenieros.

Preguntas

Preguntas que hacen los equipos de TI.

¿Podemos empezar con poco y crecer después?

Sí. Empieza con la fila que corresponde a las personas que trabajan a la vez hoy. Una base de datos gestionada pasa a un tamaño mayor con un ajuste y un reinicio de unos minutos, y los servidores E1 se añaden solos con la carga. Solo el tamaño de prueba no está pensado para el trabajo diario.

¿Por qué no una base de datos burstable más barata?

Una base de datos burstable solo es rápida mientras tiene créditos de CPU. Los ingenieros trabajan durante horas, los créditos se agotan y la base de datos cae a una fracción de un núcleo: cada clic espera entonces segundos. El dinero ahorrado se pierde muchas veces en ingenieros esperando.

¿Revisáis nuestros tamaños antes de empezar?

Sí. Dinos cuántos ingenieros trabajarán a la vez y qué tamaño tienen tus proyectos, y confirmamos los tamaños o los ajustamos. Para más de 200 ingenieros a la vez dimensionamos la instalación con una prueba de carga. Escribe a ventas.
