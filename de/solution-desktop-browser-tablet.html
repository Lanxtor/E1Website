In E1 planen Sie in der Desktop-App für Windows oder macOS oder im Browser, ohne etwas zu installieren, und prüfen in jedem Browser auf einem Laptop oder Tablet. Jeder Ort öffnet dasselbe Projekt auf demselben Server mit demselben Konto, sodass keine Dateien zu kopieren und nichts zu synchronisieren ist. Eine an einem Ort vorgenommene Änderung ist innerhalb von Sekunden überall zu sehen.

Desktop

Die Desktop-App für Windows und macOS

E1 ist eine Desktop-App für Windows 10 oder 11 (64 Bit) und für Macs mit Apple Silicon ab macOS 12. Beide sind signiert und halten sich selbst auf dem neuesten Stand.

Laden Sie sie über E1 holen herunter: Ihr eigenes System wird zuerst angeboten. Die Windows-App ist von Lanxtor LLC signiert; die Mac-App ist von Apple signiert und notarisiert, sodass macOS keine Warnung vor einem nicht identifizierten Entwickler zeigt. Beim ersten Start wählen Sie den Server: Use E1 Cloud, oder tippen Sie die Adresse des eigenen Servers Ihrer Organisation. Sie melden sich mit demselben Konto wie im Browser an, und Ihre Projekte sind da.

In der Desktop-App sind schwebende Fenster echte Fenster: Ziehen Sie einen Tab heraus, um nebeneinander oder auf einem zweiten Bildschirm zu arbeiten, und er öffnet sich beim nächsten Start wieder dort, wo er war. Die App sucht beim Start und alle vier Stunden nach einer neuen Version, lädt sie im Hintergrund herunter und bittet Sie um einen Neustart. Sie laden nie wieder ein Installationsprogramm herunter, und ein Update geht nie auf eine ältere Version zurück.

Browser

E1 im Browser, ohne etwas zu installieren

In E1 ist der Browser ein vollwertiger Arbeitsplatz, kein eingeschränkter Viewer: Öffnen Sie app.lanxtor.com oder die E1-Adresse Ihrer Organisation, melden Sie sich an, und dieselben Projekte öffnen sich mit denselben Werkzeugen.

Der Browser passt zu jedem Computer, auch zu Linux, Intel-Macs und Windows auf Arm, für die es kein Desktop-Installationsprogramm gibt. Die E1 Cloud wird mit aktuellem Google Chrome und Microsoft Edge getestet. Auf der Kontoseite der Website führt Open E1 in the browser Sie direkt hinein.

E1 speichert jede Änderung beim Arbeiten auf dem Server. Ihre Tabs, Ihre Auswahl und die von Ihnen geöffneten Zeilen werden für Sie auf dem Server gehalten und kommen nach einem Neuladen zurück; Ihr Erscheinungsbild und die Breite der Bereiche werden pro Browser gehalten. Im Browser öffnen sich schwebende Fenster als Pop-ups.

Prüfung

Von einem Laptop oder Tablet aus prüfen

In E1 arbeiten Reviewer und Viewer im echten Modell, nicht in einem exportierten PDF: Ein Reviewer kann redlinen, kommentieren und genehmigen, und ein Viewer sieht alles schreibgeschützt.

Ein Reviewer markiert einen 2D-Bereich mit Wolken, Pfeilen, Text, Pins und Stempeln auf einer Ebene Markups und kann die Zeichnung nie ändern. Jede Markierung hat eine Karte mit ihrer Diskussion und ihrem Status, und eine Prüfrunde endet mit einem Kommentarlösungsblatt. Viewer sehen jedes Projekt, jede Zeichnung, Liste und jedes Dokument, die ihnen gegeben werden, in E1 selbst. Auftraggeber und Auftragnehmer, die als Gäste in ein Projekt eingeladen werden, sehen es kostenlos an.

Auf einem Tablet läuft E1 im Browser. Manche Bildschirme sind für einen Finger gemacht: Die Feldansicht der Drahtbewegungen zeigt jedes Abklemmen und Auflegen in großen Zeilen, und ein Tipp hakt eine Bewegung mit Ihrem Namen und der Uhrzeit ab. E1 Reviewer für iPad und E1 Mobile für iPhone kommen in den App Store, wie E1 holen zeigt.

Ein Projekt

Dasselbe Projekt, dasselbe Konto, wo immer Sie sind

In E1 liegt das Projekt auf dem Server, nicht auf einem Gerät: Die Desktop-App und der Browser sind zwei Wege zu denselben Daten.

Beginnen Sie eine Änderung an Ihrem Schreibtisch in der Desktop-App und prüfen Sie sie später in einem Browser in der Anlage oder in einem Besprechungsraum. Die Änderung eines Ingenieurs erreicht alle, die das Projekt geöffnet haben, innerhalb von Sekunden, vom Server übertragen, ohne Neuladen. Avatare in der Symbolleiste eines 2D-Bereichs zeigen, wer ihn noch geöffnet hat, und ändern zwei Personen dasselbe, wird die erste Änderung übernommen und die zweite mit einer klaren Meldung abgelehnt.

Eine E1-Lizenz gilt für eine namentlich genannte Person, und jede Änderung und Genehmigung wird unter diesem Namen protokolliert. Ein Konto kann an bis zu drei Orten gleichzeitig geöffnet sein, Browser und Desktop-App zusammen. An einem vierten Ort fragt E1, welcher abgemeldet werden soll.

  • Desktop-App: Windows 10 oder 11 (64 Bit); macOS 12 oder neuer auf Apple Silicon.
  • Browser: aktuelles Google Chrome und Microsoft Edge, auf jedem Computer oder Tablet.
  • Server: die E1 Cloud oder die eigene E1-Installation Ihrer Organisation.
  • Updates: Der Server und die Desktop-App melden Ihnen jeweils, wenn eine neue Version bereit ist.
Fragen

Fragen, die Ingenieure stellen.

Läuft E1 auf einem Mac?

Ja. Die Desktop-App läuft auf Macs mit Apple Silicon ab macOS 12, signiert und von Apple notarisiert. Auf einem Intel-Mac nutzen Sie E1 im Browser.

Gibt es eine Linux-Version?

Es gibt keine Desktop-App für Linux. E1 läuft unter Linux im Browser, ohne dass etwas installiert werden muss.

Ist die Browser-Version gegenüber der Desktop-App eingeschränkt?

Nein. Beide öffnen dieselben Projekte auf demselben Server mit demselben Konto und denselben Werkzeugen. Die Desktop-App ergänzt echte schwebende Fenster, die sich dort wieder öffnen, wo sie waren, und ihre eigenen Updates.

Können wir E1 auf einem iPad oder einem anderen Tablet nutzen?

Ja, im Browser. E1 Reviewer für iPad kommt in den App Store; bis dahin prüfen Sie auf einem Tablet im Browser.

Kann sich die Desktop-App mit unserem eigenen Server verbinden?

Ja. Wählen Sie beim ersten Start Use E1 Cloud oder tippen Sie die Serveradresse Ihrer Organisation, zum Beispiel https://e1.example.com, und klicken Sie auf Connect. Die App merkt sie sich.

Wie wird die Desktop-App aktualisiert?

Sie sucht beim Start und alle vier Stunden nach einer neuen Version, lädt sie im Hintergrund herunter und bittet Sie um einen Neustart. Check for Updates… im App-Menü sucht sofort.

Kann ich gleichzeitig auf meinem Laptop und einem Tablet angemeldet sein?

Ja. Ein Konto kann an bis zu drei Orten gleichzeitig geöffnet sein. An einem vierten fragt E1, welcher Ort abgemeldet werden soll.
