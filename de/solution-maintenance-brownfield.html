Brownfield-Engineering und Anlagenänderungen, an der Anlage, die Sie schon haben.

In E1 ist eine bestehende Anlage kein Sonderfall. Sie übernehmen ihre P&IDs und Listen aus CAD, PDF, DEXPI und Excel, erfassen, was installiert ist, als As-built, ändern es in einem Änderungs-Branch, während das gemeinsame Design unberührt bleibt, und geben dem Feld eine Liste genau dessen, was abzuklemmen und aufzulegen ist. Jede Änderung wird protokolliert, verglichen und kann rückgängig gemacht werden.

Import

Von den Zeichnungen ausgehen, die Sie schon haben

In E1 werden ältere P&IDs zu echten Objekten: File → Import ▸ Legacy diagrams liest DXF- und Vektor-PDF-Zeichnungen, und File → Import liest DEXPI-2.0-Dateien und Excel-Arbeitsmappen.

Die meisten Brownfield-Anlagen wurden in AutoCAD oder einem ähnlichen CAD-Programm gezeichnet. E1 liest die als DXF gespeicherten Zeichnungen. Jeder Block, etwa eine Pumpe, eine Armatur oder ein Tank, wird zu einem Objekt der Klasse, nach der er benannt ist oder der er ähnelt, platziert dort, wo er gezeichnet ist, und die Linien auf jeder Ebene werden zu Rohren, Signalen oder Kabeln, die mit den Symbolen verbunden sind, an denen sie enden. Eine DWG-Datei wird in Ihrem CAD-Programm geöffnet und zuerst als DXF gespeichert; E1 erkennt eine DWG-Datei und sagt es.

Oft ist die einzige Kopie eines P&ID ein PDF. Wurde es aus CAD exportiert, findet E1 die Symbole zwischen den Linien, gruppiert gleich gezeichnete, erkennt jede Gruppe anhand der Symbole von E1, nimmt den Text neben einem Symbol als dessen Tag und erstellt aus jeder Leitungsnummer eine Rohrleitung. Importieren Sie alle Blätter eines Satzes zusammen, sodass ein auf zwei Blättern gezeichneter Tag ein Objekt ist. Ein gescanntes Bild kann nicht gelesen werden, und E1 sagt es.

Jeder Import schlägt für jede Art von Ding eine Klasse mit Konfidenz und Begründung vor, zeigt jede Änderung, bevor etwas gespeichert wird, und nimmt alles mit einem Strg+Z zurück. Importieren Sie eine überarbeitete Zeichnung oder Arbeitsmappe erneut, werden die bereits vorhandenen Objekte aktualisiert, nie dupliziert. Ein Wert, den jemand in E1 geändert hat, wird nie ohne Ihre Entscheidung überschrieben: Sie wählen Use file oder Keep E1.

  • DXF-Zeichnungen aus AutoCAD und anderen CAD-Programmen, bis zu 50 MB je Datei.
  • Vektor-PDF-Zeichnungen, bis zu 50 MB und 50 Seiten je Datei.
  • DEXPI-2.0-P&IDs aus anderen P&ID-Werkzeugen, mit ihrer Zeichnung als Hintergrund.
  • Excel-Arbeitsmappen und CSV: Ausrüstungslisten und Instrumentenlisten, eine Klasse pro Blatt, ein Attribut pro Spalte.
As-built

Erfassen, was installiert ist, als As-built

In E1 trägt jede aufgelegte Ader und jede Klemme einen Bauzustand: Designed, Issued for construction, Installed, Terminated, Loop-checked, As-built oder To be removed.

Die Verdrahtung einer bestehenden Anlage oder eines Lieferantenschranks kommt als Anschlussliste in CSV oder Excel nach E1. Alex zeigt zuerst, was er tun würde, und erstellt dann die Gehäuse, Leisten, Klemmen, Kabel und Adern, die noch nicht im Projekt sind. Jede Ader wird an beiden Enden aufgelegt, fest, mit dem Umfang Existing und dem Status As-built, sodass das neue Design darum herum entsteht und E1 sie nie von selbst verschiebt.

Dokumente bleiben, wo sie sind, wenn das passt. Ein Hyperlink in E1 steht für eine Datei, die in Ihrem Dokumentenmanagementsystem liegt, und öffnet sie dort; setzen Sie ihn mit einer Pumpe, einem Motor, einem System oder einem 2D-Bereich in Beziehung, und die Datei wird von diesem Objekt aus gefunden. Ein anderswo erstelltes PDF kann als hochgeladenes Dokument mit eigenen Revisionen aufbewahrt werden.

Reviewer bestätigen die Zeichnung gegenüber der Anlage mit den Markup-Stempeln des Projekts. Field verified und As-built gehören zu den Stempeln, mit denen ein Projekt startet, und jeder Stempel trägt den Namen des Reviewers und das Datum.

Änderungen

Anlagenänderungen in einem Branch, nicht im Live-Design

In E1 ist eine Änderung ein Branch eines Teils des Designs: Sie ändern ihn, während main bleibt, wie es ist, und spielen ihn als eine Änderung zurück, wenn er bereit ist.

Starten Sie einen Branch von den Objekten, die die Änderung berührt, in der Zeichnung oder im Explorer. E1 fügt hinzu, was damit kommt, etwa Stutzen und angeschlossene Leitungen, und erklärt, warum. Im Branch legt Show main die Version von main des 2D-Bereichs über Ihre, sodass Sie genau sehen, was sich bewegt. Ändert main ein Objekt, das der Branch ändern darf, wird der Branch informiert, und Pull from main übernimmt die Änderung Wert für Wert, mit jedem Konflikt zur Lösung durch eine Person.

Fertige Arbeit kann als Inbetriebnahmepaket herausgeschnitten werden: Zeichnen Sie um die Ausrüstung, geben Sie dem Paket seine Termine und seinen Inbetriebnahmeleiter, markieren Sie es als bereit und pushen Sie nur diesen Teil. Ein Branch-Typ kann vor main eine Prüfung durch einen Kollegen verlangen. Jeder Push hinterlässt ein Protokoll mit jedem Feld vorher und nachher. Branches sind ausführlich unter Branches und Änderungen beschrieben.

Feldarbeit

Änderungen nach der Ausgabe: eine Wire-Move-Liste für das Feld

In E1 wird herausgegebene Verdrahtung nie stillschweigend verschoben: Sobald Kabel gezogen und angeschlossen sind, wird eine Änderung zu einer Liste dessen, was abzuklemmen und aufzulegen ist, Klemme für Klemme.

Verschieben Sie einen Messumformer in einen anderen Klemmenkasten, und E1 schreibt die Bewegungen auf den Tab Changes der Seite Wiring: Lift, Land oder Remove, mit Ader, deren Aderkennzeichen, der Klemme und dem Grund. Ein Gerät, dessen Verdrahtung installiert ist, kann nicht einfach gelöscht werden; es wird zuerst zum Entfernen markiert, und seine Verbindungen stehen auf der Liste.

Die Feldansicht zeigt die Bewegungen in großen Zeilen nach Gehäuse und Leiste, auf einem Tablet leicht mit dem Finger zu treffen. Ein Tipp hakt eine Bewegung mit Ihrem Namen und der Uhrzeit ab, und ein Kommentar geht an der Klemme zurück an die Planung. Die Bewegungsliste lässt sich auch nach Excel exportieren. Compare with zeigt, was seit einer herausgegebenen Revision der Schleifenschemas oder seit einem Datum hinzugefügt, entfernt und geändert wurde.

Redlining

Redlining und Änderungswolken auf der Zeichnung

In E1 kommen Redlines auf eine Ebene Markups, die die Zeichnung nie ändert, und jede Markierung hat eine Karte mit ihrer Diskussion und ihrem Status.

Reviewer markieren einen 2D-Bereich mit Wolken, Pfeilen, Text, Pins und Stempeln; ein Reviewer kann markieren, die Zeichnung aber nie ändern. Eine Markierung wird akzeptiert, abgelehnt, beantwortet oder eingearbeitet, und beim Einarbeiten werden die Änderungen genannt, die es erledigt haben. Ein markierter Ausdruck trägt jede Markierung als echten PDF-Kommentar, und die kommentierte Kopie eines Reviewers dieses Ausdrucks wird in die Prüfrunde zurückgelesen. Die Liste Markups exportiert das Kommentarlösungsblatt.

Changes since… in einem 2D-Bereich umwölkt alles, was seit einem Tag, einer Revision oder einer Version hinzugefügt, gelöscht, geändert oder verschoben wurde, mit vorher und nachher und wer es geändert hat. Das PDF einer Revision umwölkt, was sich geändert hat, mit einem Dreieck, das ihre Bezeichnung trägt, und listet jede Änderung neben dem Schriftfeld auf. Der Tab History jedes Objekts zeigt, wann, wer und was geändert wurde, und Undo this change nimmt eine zurück.

Fragen

Fragen, die Ingenieure stellen.

Kann E1 DWG-Dateien importieren?

E1 liest DXF. Öffnen Sie die DWG in Ihrem CAD-Programm, nutzen Sie Save As → DXF und importieren Sie diese Datei mit File → Import ▸ Legacy diagrams ▸ DXF drawing…. E1 erkennt eine DWG-Datei und weist Sie an, sie als DXF zu speichern.

Kann E1 ein gescanntes P&ID lesen?

Nein. E1 liest aus einem CAD-Programm exportierte PDFs (Vektor-PDFs). Eine gescannte Zeichnung ist ein Bild; E1 sagt es und importiert nichts.

Was passiert, wenn ich eine überarbeitete Zeichnung importiere?

Objekte, die bereits im Projekt sind, werden anhand ihres Tags gefunden und aktualisiert, nie dupliziert. Ein Wert, den jemand in E1 geändert hat, wird neben dem Wert der Datei gezeigt, und Sie wählen vor Apply Use file oder Keep E1. Ein verschobenes Symbol ist ebenfalls eine Platzierung, über die Sie entscheiden.

Wie viele ältere Zeichnungen dürfen wir importieren?

Jede Organisation darf in den Plänen University, Essentials und Standard 100 DXF- und 100 PDF-Zeichnungen importieren, in Enterprise beliebig viele. Eine Datei zählt einmal pro Projekt, sodass eine überarbeitete Version nichts weiter verbraucht. Excel- und DEXPI-Importe haben keine Grenze. Siehe Pläne und Preise.

Welche Pläne enthalten Änderungs-Branches?

Änderungs-Branches und Inbetriebnahmepakete sind in den Plänen University, Standard (Editor) und Enterprise enthalten. Essentials (Editor Basic) hat DXF- und Excel-Import, Redlining und Dokumentenkontrolle, aber keine Branches, keinen PDF- und keinen DEXPI-Import.

Ändert ein Redline die Zeichnung?

Nein. Markierungen liegen auf ihrer eigenen Ebene Markups. Sie ändern nie die Zeichnung, ihre Objekte, deren Verlauf oder deren Revisionen; blendet man die Ebene aus, zeigt sich die Zeichnung unverändert.

Kann das Feld Verdrahtungsänderungen auf einem Tablet abhaken?

Ja. Auf der Seite Wiring zeigt Changes → Field view die Drahtbewegungen in großen Zeilen für einen Finger. Ein Tipp markiert eine Bewegung mit Ihrem Namen und der Uhrzeit als erledigt, und ein Kommentar geht an der Klemme zurück an die Planung.
