About this guide

E1 has one assistant, Alex, in the side panel on the right of the window, with one row of tabs: Co-engineer | Ask | Agent | Plan | E1 Guide. In Co-engineer, Alex is built into E1: it reads your drawing as you work and raises warnings, questions and suggestions, with no language model and nothing sent outside. In Ask, Agent and Plan, Alex answers questions in your own words with the help of a language model, and in Agent mode changes the project, with review and undo. E1 Guide teaches you E1 where you are.

The usual order

  1. Find the side panel and its tabs: The Alex panel.
  2. Let Alex help and read what it finds: Alex, Skill and Level, Alex's cards, Simulation results, Marks on the drawing, Filters, Not applicable and Suggestions while you draw.
  3. Teach Alex your company's rules: Alex knowledge, Team memory and Pipe class checks. Use Alex's lists: Instrument index and Heat and material balance import.
  4. Ask Alex in your own words: Ask, Agent and Plan, What each of them may do, Review changes first, Protect the arrangement, Undo on a reply and What is always held.
  5. Give Alex more to work with: Attachments, Voice input, Which model, Engineering patterns and Alex's review behind the answer.
  6. Know the limits: Prompt-injection safety, Without a language model, and what is planned.

Before you start

  • A project is open, with a 2D space (drawing) for Alex. See The 2D space view.
  • Co-engineer and E1 Guide need no model and work in every installation. Ask, Agent and Plan need a model chosen by your administrator; without one they are greyed out and you do everything else by hand, as described in the other guides.
  • Changing the project, by hand or by asking Alex, needs a license and project role that may edit.

On the website and in the price list, "Alex, the AI co-engineer" stands for E1's AI as a whole.

Alex: let the built-in engineering co-worker help

AvailableUpdated 2026-11-13AI-alex

Alex reads the 2D space you are drawing, like a process or automation engineer looking over your shoulder, and lists warnings, questions and suggestions. It is a local AI: it calls no language model and sends nothing outside E1. Alex is off until you click Let Alex help.

Where
Alex → Co-engineer → Let Alex help; Stop Alex in the same place switches it off. On every tab of Alex, the switch beside Alex's name reads Off or Reviewing; a click turns Alex on or off.
Who
Anyone who may edit the 2D space
Before you start
A 2D space is open, for example Assets in the demo project.

Steps

#ActionExpected result
1Open a 2D space and click Co-engineer in Alex.The header says Off, with the text "Alex is off. Let Alex help to have a process, automation or electrical engineer read your drawing as you work: built in, nothing leaves E1." and the button Let Alex help, with Alex's sparkle icon on its left.
2Look at the drawing toolbar.It has no Alex button: Alex is switched on and off in the Alex tab only.
3Click Let Alex help.The button is replaced by Stop Alex, next to Show Alex’s marks on the drawing, and the switch beside Alex's name reads Reviewing. The panel header reads "Plant engineer · local AI, no cloud", briefly with "· reading the 2D space…".
4Wait a few seconds.The panel lists counts and groups such as Warnings, Questions and Design suggestions; marks appear on the drawing. A clean 2D space shows "Nothing to add on ‹2D space›. Looks good."
5Reload the page.Alex is still on.
6Click Stop Alex.Alex turns off completely: the panel shows Let Alex help again, the switch reads Off and the marks disappear.

Alex reads the 2D space when you open it, and about half a second after a change of yours settles, never while you are dragging. A change another engineer makes to the 2D space shows on your screen at once; Alex reads it with your next change. It keeps working with no language model: its review uses none. With no 2D space open, the panel says "Open a 2D space and Alex will read it."

Whether Alex is on is remembered in this browser only. No manual-review check covers Alex yet; test it with the steps in these guides.

E1 Guide: Alex shows you how, where you are

AvailableSince 2026-11-07Updated 2026-11-13AI-alex-trainerRoadmap 26.1, 26.3

Alex has a second mode, E1 Guide. Instead of reviewing your drawing, Alex offers short lessons for the place you are in, for example in Configuration → Object classes: look up a class, add a new class, give a class more attributes. A lesson shows a bubble on the real button, tells you what it is for and what to click, and goes on one bubble at a time. Above all, the bubbles teach what you cannot see on screen: double-clicks, right-click menus, dragging, keys and the order of the steps, each shown as a badge. Every bubble links to the matching section of this guide. To learn something of another place, search for it, or open All topics to see every lesson of E1 by topic; Alex asks before taking you there.

Where
Alex → E1 Guide, or Help → Alex E1 Guide
Who
Everyone; a lesson can be taken as often as you like
Before you start
The Alex panel is shown.

6Click Back, then End tour (or press Esc while the bubble has the focus).The bubble goes back one step; End tour closes it.

Next always goes on. Lessons that wait for a click show Skip instead of Next. A lesson that needs a project, a 2D space or an object opens it in the project of what you selected (else the first project); without one, Alex says what to open first.

Read and act on Alex's cards

AvailableSince 2026-11-06Updated 2026-11-13AI-alex-cards

Each thing Alex notices is a card in one of the groups Warnings, Questions, Design suggestions, Data suggestions, Notes and, at Mentor level, Tips. A card says why, shows where on the drawing, and offers a fix, an answer field or a way to set it aside.

Where
Alex → Co-engineer, below the counts
Who
Reading: everyone. Apply and Save change the project and need edit rights.
Before you start
Alex is on, on a 2D space with pumps and pipes.

Steps

#ActionExpected result
1Look at a card without opening it.It shows its discipline (Process, Automation, Electrical, HAZOP or Drawing), its title and a chevron, sometimes a badge (see the list below), and its buttons even while it is closed: Show, Not applicable and Ask Alex; under Design suggestions, Show, Apply, Reject and Ask Alex. Ask Alex is greyed out when no AI model is set up.
2Click the chevron of a design suggestion card.The card opens with its message and Why?. A design card has no Not applicable.
3Click Why?.The reason appears; the button now reads Hide why.
4Click Show.The drawing shows the suggestion as ghost symbols where they would go; what it would take away is dashed in red. The button now reads Hide.
5Click Apply.The symbols are placed on the 2D space for real and the card goes away. Reject instead puts the suggestion away for this 2D space.
6Open a question card (for example "Pump1: rated power?"), type 10 in the field and click Save.The value is written to the object and the card disappears.
7Open a line data card on the pump inlet line. Enter Fluid "Cooling water", Phase "liquid", Flow rate 120, Operating pressure 5, Operating temperature 25 and Nominal size "DN 50", then click Save.The question goes away and a warning that the velocity is high appears, giving the speed in m/s and marked on the line.

Badges on a card: After your change (Alex's suggestion for your last change, already drawn on the 2D space; always the first design card), On the drawing (a design suggestion: a change to the drawing), Data (a data suggestion: a value for the object's data; nothing on the drawing changes), Company convention (from your company's standards) and Usual at your company (team memory).

Cards other than design suggestions have Show (when they point at something on the drawing), Not applicable (not on tips) and Ask Alex (it opens the Ask tab with the card in the text box). Some fill in a value with one click; the button names the value, for example Use B1.

What Alex checks: line velocity by service, pressure drop, erosional velocity and design margin; sour service and CO₂; instrument loops, tags, fail positions, interlocks with cause and effect, and anti-surge; questions about motor starting and signal types. The line checks need the line list attributes of the Plant library 1.3.0 or newer.

Read Alex's simulation results

AvailableSince 2026-11-08Updated 2026-11-09AI-alex-simulation

When a simulator in Alex has run on the open 2D space (a process flash or flowsheet, an electrical load flow, short circuit, motor start or arc flash), its results appear in the Alex panel under Simulation results, as cards with a violet Simulation badge.

Where
Alex → Co-engineer → group Simulation results
Who
Everyone
Before you start
Alex is on, at the level Normal or Mentor (simulation results are not shown at Quiet), and the 2D space has the data the simulation needs.

Steps

#ActionExpected result
1Look at the counts at the top of Co-engineer.A count such as "1 simulation result" is shown with the other counts.
2Open a card under Simulation results.The card shows the method, the status, the inputs, the assumptions, any warnings and the result tables. A red Not converged means the numbers are not reliable.
3Scroll a wide table sideways.The table scrolls inside the card; the panel stays in place.
4Click Export results (Excel).A workbook downloads with a Summary sheet and one sheet per table.
5Click Show.The equipment the result is about is selected on the drawing. Simulation results put no mark on the drawing.

What Alex simulates

  • Flash of a line (Process engineer): a line whose line list has a composition (for example "C1 85, C2 7, C3 3, CO2 2, N2 3 mol%"), a pressure and a temperature gets its phases, their amounts and compositions, density, Z, enthalpy, Cp and viscosity (Peng-Robinson).
  • Heat and material balance (Process engineer): when lines carry a composition, Alex solves the 2D space along the drawing (valves, pumps, compressors, heaters and coolers, exchangers, mixers and tees, splitters, separators; columns are boundaries). Each unit needs its specification on its attributes (outlet pressure or pressure drop, outlet temperature or duty, efficiency); Alex asks for what is missing and never assumes it. The card has the Streams, Compositions (mol %), Units and Balance tables; a partial or not converged status says what stopped it. Under Data suggestions, Write to the line list writes a line's calculated temperature, pressure, flow and phase into its row when you press it.
  • Load flow and short circuit (Electrical engineer, on a single line diagram): bus voltages, branch loading and losses, and the IEC 60909 short-circuit current and peak at every board, compared with the ratings you entered.
  • Motor starting: the voltage at the motor and at every board while each motor starts with its starting method.
  • Arc flash (IEEE 1584-2018): the incident energy and arc flash boundary at each board, only where the protective device's clearing time is entered; without it Alex asks for it.
  • Earth faults (IEC 60909): single line-to-earth, line-to-line and double line-to-earth fault currents at every board, from the transformers' vector groups and neutral earthing and the zero-sequence data; what is not entered is asked, never assumed.
  • Harmonics (IEEE 519-2014): THDv at every board, TDD and harmonic currents at the point of common coupling compared with the limits, and a resonance scan where a capacitor bank is entered; drives need the manufacturer's harmonic spectrum, which Alex asks for.
  • Protection coordination (IEC 60255-151, IEEE C37.112, IEC 60947-2): from the relay, trip unit and fuse settings you entered, the operating time of each device at the calculated fault currents, the margin between devices in series, and a time–current table; where a breaker's settings and opening time are entered, the arc flash uses the clearing time they give.
  • Battery sizing and UPS autonomy (IEEE 485, IEEE 1115): the cell size from the duty cycle and the manufacturer's discharge data you entered, the number of cells, and a UPS's backup duty and loading; without the data Alex asks.

Every assumption a simulation makes (a typical value, a parameter taken as zero) is listed on its card. Not applicable hides a card on this 2D space only.

Stored assistants

AvailableSince 2026-11-11AI-stored-assistantsRoadmap 18.1–18.6, 17.3Review checks Q1, Q2, Q3, Q4, Q5

Save what Alex did in one reply as an assistant: its steps, in order, with what you had selected and the project as parameters. Run it again on another selection without Alex, as one change that one undo takes back, or as a preview first.

Where
Under a reply that changed something → Save as assistant; the left rail → Assistants
Who
Saving needs Create assistants and running Run assistants (Engineer and above). Each step also needs its own permission: a step you may not do stops the run before anything changes.
Before you start
Alex changed something in one reply, for example added a valve to the selected folder and described it.

Save a reply as an assistant

#ActionExpected result
1Under the reply, click Save as assistant.Alex notes “Saved as the assistant …, with 2 steps.” and Assistants opens on it.
2Read its Steps.Each step is one sentence, for example “Create object: with the selected object (selected), the current project (project)”; open one to see its command and input.
3Check its Parameters.What you had selected became selected (The selection) and the project project (The current project). An object a step made and a later step used is taken from that step's result. Change a parameter's Comes from to Asked when it runs or Always this value, or its label, and click Save: a new version.

Record by hand

#ActionExpected result
1In Assistants, click Record.It reads ● Recording: 0 steps, and the Assistants button on the left rail shows ●.
2Select an object and make your changes, for example its description.Each change is kept as a step with what it changed; opening tabs and selecting are not steps.
3Back in Assistants, click Stop.A new assistant Recorded … opens with the steps, and what you had selected as the parameter selected.

Repeat and skip

  • For each selected object on a selection parameter repeats the steps that use it once per selected object; the steps then read “For each of the selected object (item)”.
  • Open a step and choose Skip if the object already has a value and the attribute: a step whose condition holds is reported Skipped with the reason.
  • A repeat stops at the first object that fails and keeps nothing; tick Keep the ones that succeed when one fails to keep the objects that went through, and the failed one is reported.
  • Propose parameters suggests recorded values (an object, a number) to ask for when it runs; Make parameter takes one.

A script step in a stored assistant

AvailableSince 2026-11-12Updated 2026-11-12AI-assistant-scriptRoadmap 18.6Review check Q7

A step that calculates values from the assistant's parameters and earlier results, with the steps of a calculation rule, for the steps after it.

Where
Assistants → an assistant → Add script step
Who
Whoever may make assistants
Before you start
An assistant that creates a valve, with the parameters Design flow (flow) and Unit number (unit).

Steps

#ActionExpected result
1Click Add script step.A script step first, its inputs the parameters.
2Write its steps: { "calculate": "flow * 1.1", "as": "design" }, a choose of DN 150 above 100 m³/h else DN 80 as size, and { "compose": "XV-{unit}01", "as": "tag" }.The step reads “Calculate design, size, tag”.
3In the valve step use {s1c.result.tag}; Save and run it with 120 m³/h and unit 2.XV-201 is made.

A script uses the steps of a calculation rule: Compose, Copy, Map, Calculate (+ − × ÷, powers, sqrt, min, max, round, each quantity in the unit you name), Choose, Format and Compare. It only calculates: it reads and writes nothing, so a run with a value that is not a number stops at the script with the reason and keeps nothing.
