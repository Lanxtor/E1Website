Import

Start from the drawings you already have

In E1, legacy P&IDs become real objects: File → Import ▸ Legacy diagrams reads DXF and vector PDF drawings, and File → Import reads DEXPI 2.0 files and Excel workbooks.

Most brownfield plants were drawn in AutoCAD or a similar CAD program. E1 reads the drawings saved as DXF. Each block, such as a pump, a valve or a tank, becomes an object of the class it is named for or looks like, placed where it is drawn, and the lines on each layer become pipes, signals or cables connected to the symbols they end on. A DWG file is opened in your CAD program and saved as DXF first; E1 recognizes a DWG file and says so.

Often the only copy of a P&ID is a PDF. When it was exported from CAD, E1 finds the symbols among the lines, groups the ones drawn alike, recognizes each group against E1's symbols, takes the text beside a symbol as its tag and makes a pipeline from each line number. Import all sheets of a set together, so a tag drawn on two sheets is one object. A scanned image cannot be read, and E1 says so.

Every import proposes a class for each kind of thing with a confidence and a reason, shows every change before anything is stored, and takes it all back with one Ctrl+Z. Import a revised drawing or workbook again and the objects already there are updated, never duplicated. A value someone changed in E1 is never overwritten without your decision: you choose Use file or Keep E1.

  • DXF drawings from AutoCAD and other CAD programs, up to 50 MB each.
  • Vector PDF drawings, up to 50 MB and 50 pages per file.
  • DEXPI 2.0 P&IDs from other P&ID tools, with their drawing kept as the background.
  • Excel workbooks and CSV: equipment lists and instrument indexes, one class per sheet, one attribute per column.
As-built

Record what is installed, as-built

In E1, every landed core and every terminal carries a construction status: Designed, Issued for construction, Installed, Terminated, Loop-checked, As-built or To be removed.

The wiring of an existing plant, or of a vendor's panel, comes into E1 as a termination list in CSV or Excel. Alex shows first what it would do, then makes the enclosures, strips, terminals, cables and cores that are not yet in the project. Every core is landed at both ends, fixed, with the scope Existing and the status As-built, so new design is made around it and E1 never moves it by itself.

Documents stay where they are when that suits you. A hyperlink in E1 stands for one file kept in your document management system and opens it there; relate it to a pump, a motor, a system or a 2D space and the file is found from that object. A PDF made elsewhere can be kept as an uploaded document with its own revisions.

Reviewers confirm the drawing against the plant with the project's markup stamps. Field verified and As-built are among the stamps a project starts with, and each stamp carries the reviewer's name and the date.

Modifications

Plant modifications in a branch, not in the live design

In E1, a modification is a branch of part of the design: you change it while main stays as it is, and push it back as one change when it is ready.

Start a branch from the objects the modification touches, on the drawing or in the explorer. E1 adds what comes with them, such as nozzles and connected lines, and explains why. Inside the branch, Show main lays main's version of the 2D space over yours, so you see exactly what moves. When main changes an object the branch may change, the branch is told, and Pull from main brings the change in value by value, with any conflict for a person to resolve.

Finished work can be cut out as a commissioning package: draw around the equipment, give the package its dates and commissioning lead, mark it ready, and push only that part. A branch type can require a review by a colleague before main. Every push leaves a protocol with every field before and after. Branches are described in full on Branches and modifications.

Field work

Changes after issue: a wire move list for the field

In E1, issued wiring is never moved silently: once cables are pulled and terminated, a change becomes a list of what to lift and what to land, terminal by terminal.

Move a transmitter to another junction box and E1 writes the moves on the Changes tab of the Wiring page: Lift, Land or Remove, with the core, its wire number, the terminal and the reason. A device whose wiring is installed cannot simply be deleted; it is marked to be removed first, and its connections are on the list.

The field view shows the moves in large rows by enclosure and strip, easy to hit with a finger on a tablet. One tap ticks a move off with your name and the time, and a comment goes back to design on the terminal. The move list also exports to Excel. Compare with shows what was added, removed and changed since an issued revision of the loop diagrams, or since a date.

Redlining

Redlining and change clouds on the drawing

In E1, redlines go on a Markups layer that never changes the drawing, and every markup has a card with its discussion and its status.

Reviewers mark up a 2D space with clouds, arrows, text, pins and stamps; a Reviewer can mark up but never change the drawing. A markup is accepted, rejected, answered or incorporated, and incorporating it names the changes that did it. A marked-up print carries each markup as a real PDF comment, and a reviewer's annotated copy of that print reads back into the review round. The Markups list exports the comment resolution sheet.

Changes since… on a 2D space clouds everything added, deleted, modified or moved since a day, a revision or a version, with before and after and who changed it. A revision's PDF clouds what changed with a triangle carrying its label and lists each change beside the title block. Each object's History tab shows when, who and what changed, and Undo this change takes one back.

Questions

Questions engineers ask.

Can E1 import DWG files?

E1 reads DXF. Open the DWG in your CAD program, use Save As → DXF, and import that file with File → Import ▸ Legacy diagrams ▸ DXF drawing…. E1 recognizes a DWG file and tells you to save it as DXF.

Can E1 read a scanned P&ID?

No. E1 reads PDFs exported from a CAD program (vector PDFs). A scanned drawing is an image; E1 says so and imports nothing.

What happens when I import a revised drawing?

Objects already in the project are found by their tag and updated, never duplicated. A value someone changed in E1 is shown beside the file's value, and you choose Use file or Keep E1 before Apply. A moved symbol is a placement for you to decide too.

How many legacy drawings may we import?

Each organization may import 100 DXF and 100 PDF drawings on the University, Essentials and Standard plans, and any number on Enterprise. A file counts once per project, so a revised version uses nothing more. Excel and DEXPI imports have no limit. See Plans and prices.

Which plans include modification branches?

Modification branches and commissioning packages are in the University, Standard (Editor) and Enterprise plans. Essentials (Editor Basic) has DXF and Excel import, redlining and document control, but not branches, PDF or DEXPI import.

Does a redline change the drawing?

No. Markups are on their own Markups layer. They never change the drawing, its objects, their history or their revisions; hiding the layer shows the drawing unchanged.

Can the field tick off wiring changes on a tablet?

Yes. On the Wiring page, Changes → Field view shows the wire moves in large rows for a finger. One tap marks a move done with your name and the time, and a comment goes back to design on the terminal.
